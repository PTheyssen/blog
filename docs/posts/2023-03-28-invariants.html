Introduction

Invariants about programs, systems, mathematical (formal) statements about a program, system that are always true.

Landmark paper is Hoare (An Axiomatic Basis for Computer Programming), which proposes to use logical foundations for computer programming and using axioms and deduction rules (formal proofs) for proofing properties of computer programs (Hoare Logic).

Properties / invariants of computer programs (semantics of programming language), model microservices as statemachine (distributed system).

Mathematical/formal exact description of execution space, behaviour of the program.
