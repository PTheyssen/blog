# Tool for adding title to images

Simple python script that add black border at top of image and
writes some text 


Example Usage:
```
p3 add-title-border.py -i BER-01-2023/DSC06626.jpg -t "HELLO WORLD" -d "JANUARY 2023" -o test.jpg
```
